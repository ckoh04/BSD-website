# BSD 2026

Website for the 9th IEEE International Workshop on Big Spatial Data.

## Preview locally

```bash
cd /Users/ahlab/ckoh/personal-projects/BSD-website
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Publish with GitHub Pages

Push this directory to the root of a GitHub repository. In the repository's
**Settings → Pages**, choose **Deploy from a branch**, select `main`, choose
`/(root)`, and save.
